המשימות שלי — חבילת PWA מוכנה להעלאה

הקבצים בחבילה:
- index.html — האפליקציה
- manifest.webmanifest — הגדרות ההתקנה
- service-worker.js — תמיכה בעבודה אופליין
- icon-192.png / icon-512.png — אייקונים

העלאה ל-GitHub Pages:
1. פתח חשבון חינמי ב-GitHub.
2. צור Repository חדש, למשל: my-tasks.
3. העלה את כל הקבצים שבתיקייה הזו לשורש ה-Repository.
4. עבור ל-Settings > Pages.
5. ב-Build and deployment בחר Deploy from a branch.
6. בחר Branch: main ותיקייה /root ואז Save.
7. לאחר הפרסום תקבל כתובת אינטרנט.
8. פתח אותה ב-Chrome בטלפון Samsung.
9. לחץ על ⋮ ובחר "התקנת אפליקציה" או "הוספה למסך הבית".

הערה חשובה:
המשימות נשמרות מקומית במכשיר/דפדפן. מחיקת נתוני האתר בדפדפן תמחק את המשימות.
